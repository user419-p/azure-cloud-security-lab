# Azure Cloud Security Lab ☁️🔐

## Project Overview

This repository documents my practical learning journey in Microsoft Azure Cloud Security.

The objective is to develop hands-on skills in securing cloud infrastructure, managing identities and access, implementing network security controls, and monitoring cloud environments.

**Project Status:** In Progress

## Learning Objectives

- Understand Microsoft Azure security architecture.
- Implement Identity and Access Management (IAM).
- Explore Role-Based Access Control (RBAC).
- Understand Multi-Factor Authentication (MFA).
- Configure and understand Network Security Groups (NSGs).
- Learn cloud infrastructure protection.
- Explore security monitoring, logging, and threat detection.

## Technologies and Tools

- Microsoft Azure
- Microsoft Entra ID
- Azure Role-Based Access Control
- Azure Virtual Network
- Network Security Groups
- Azure Monitor
- Microsoft Defender for Cloud

## Security and Cost Awareness

All exercises will follow security best practices.

- Avoid publishing passwords, access keys, tokens, or other sensitive information.
- Use least-privilege access.
- Review resource costs before deployment.
- Remove billable resources when they are no longer needed.

## Final Goal

To develop practical Cloud Security skills and build the knowledge required to secure, monitor, and protect modern cloud environments.
